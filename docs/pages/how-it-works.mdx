# How it works

## Collection

A protocol transfers any ERC-20 fee token to its Silo address. The Silo does not call the protocol. The Silo does not index the token.

## Discovery

Solvers index `SiloCreated` events from `SiloFactory`. They read token balances from each Silo. A solver can use any data source to select a minimum useful balance.

## Competition

Each solver creates a candidate JIT order. The order sells the complete token balance. It buys the fixed resource token. It pays the fixed resource recipient.

The solver sets `buyAmount`. This value is the order limit. The Silo has no price oracle.

CoW Protocol scores competing settlements. A higher execution value improves the score when CoW recognizes the Silo as a surplus-capturing JIT owner.

## Settlement

The solution contains a pre-interaction. The pre-interaction calls `Silo.commit` through the CoW Settlement contract. The call records one order hash in transient storage. It also approves the Vault Relayer when required.

The Settlement contract then verifies the ERC-1271 signature. The Silo accepts only the committed order. Transient storage clears at the end of the transaction.

## Output

The Settlement contract sends the resource token to the immutable recipient. The recipient can be a treasury or a Burner.

The Burner sends its full balance to `0x000000000000000000000000000000000000dEaD`. This action removes standard ERC-20 tokens from circulation. It does not reduce `totalSupply` unless the token implements that behavior.
