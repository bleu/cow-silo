# Offline testing

Use Foundry mocks for the fast test loop. Run the preparation expiry test separately with isolation:

```sh
TEST_ISOLATED=true forge test --isolate --match-test testPreparationExpiresAfterTransaction
```

The optional offline profile uses the CoW Protocol Offline Playground. It starts Anvil, Settlement, Vault Relayer, orderbook, autopilot, driver, baseline solver, tokens, and test liquidity.

```sh
./integration/offline/manage.sh bootstrap
./integration/offline/manage.sh up
./integration/offline/manage.sh status
```

The profile pins an upstream commit. It stores the checkout in `.cache/`. The profile is not part of the default CI job because it builds the complete CoW service stack.

The profile starts the services but does not run a complete Silo auction scenario. The planned production test will post a Silo order to the Order Book, fill it through the usual auction flow, and check settlement. Use the official `cowprotocol/services` playground when tests need the current production service code.
