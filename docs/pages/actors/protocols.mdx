# Protocols

## Why use Silo

Silo can convert many fee tokens into one treasury token. The protocol does not need to maintain routes or run a keeper. CoW solvers compete to provide the conversion.

## Integration

1. Select the resource token.
2. Select a treasury or deploy a Burner.
3. Select an app data hash.
4. Deploy a Silo through `SiloFactory`.
5. Send fee tokens to the Silo.
6. Confirm that CoW Protocol recognizes the Silo deployment model.
7. Monitor settlements and received resource tokens.

Do not send the resource token to the Silo. The Silo cannot sell its resource token.

## Minimum balance policy

The contract does not store a minimum balance. Solvers choose when a balance is economical to settle. A protocol can publish a recommended threshold offchain. This policy does not change the Silo contract.
