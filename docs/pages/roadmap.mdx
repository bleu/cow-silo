# Roadmap

## Integration

- Test a Silo order through the intended CoW driver, including its wire `validTo`. The [offline auction clock test](/developers/offline-testing) covers contract execution without a driver.
- Add a reference solver adapter.
- Complete the CoW surplus-capturing JIT owner integration.
- Deploy and verify a testnet factory and Silo.
- Complete an independent security audit.

## Contracts

- Add a bridged Burner for chains where canonical burning must occur on another chain.
- Add tested adapters for selected non-standard tokens only when needed.

The bridged Burner is not part of the current implementation.
