# Contracts

## Silo

`Silo` is an immutable ERC-1271 order owner.

Permanent values:

- CoW Settlement contract.
- CoW Vault Relayer.
- Resource token.
- Resource recipient.
- CoW app data hash.
- Settlement EIP-712 domain separator.

Main functions:

| Function | Caller | Result |
| --- | --- | --- |
| `commit(orderHash, sellToken, sellAmount)` | Settlement only | Records one transient order hash. Approves the Vault Relayer when required. |
| `isValidSignature(hash, signature)` | Settlement | Validates the committed order through ERC-1271. |
| `verify(order)` | Any account | Checks the permanent Silo order rules. |
| `commitment()` | Any account | Returns the transient commitment for the current transaction. |

## SiloFactory

`SiloFactory` uses CREATE2. The creator address and the user salt define the deployment salt. The factory emits a `SiloCreated` event for discovery.

The factory cannot change a Silo. It cannot move Silo funds.

## Burner

`Burner` holds one immutable token. The `burn()` function transfers its full balance to the dead address. Any account can call the function. The contract has no withdrawal function.
