# TJAR comparison

This page compares TJAR with the planned CoW Silo production flow. See [How it works](/how-it-works) for the current JIT proof of concept.

| Area | Uniswap TJAR | Planned CoW Silo |
| --- | --- | --- |
| Asset holder | `TokenJar` | `Silo` |
| Conversion actor | Searcher | CoW solver |
| Selection | First valid release transaction | CoW solver competition |
| Price rule | Fixed resource payment for a release | Posted order limit subject to the protocol's output floor |
| Withdrawal | Releaser transfers selected full balances | Vault Relayer transfers funds during settlement |
| Burn sink | `Firepit` | `Burner` |
| Discovery | Factory events and offchain search | Permissionless watchtower discovers Silos and posts orders |
| Oracle | None | None |
| Routing | Searcher | Solver |

TJAR creates a speed race around a fixed onchain payment. In the planned Silo flow, a watchtower posts an order and solvers compete to fill it in a CoW auction. The executed resource-token output goes to the configured recipient. The auction can reduce value leakage when several solvers compete.
