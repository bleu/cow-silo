# TJAR comparison

Silo and TJAR keep price discovery offchain. Their execution models differ.

| Area | Uniswap TJAR | CoW Silo |
| --- | --- | --- |
| Asset holder | `TokenJar` | `Silo` |
| Conversion actor | Searcher | CoW solver |
| Selection | First valid release transaction | CoW solver competition |
| Price rule | Fixed resource payment for a release | Per-token auction minimum; the solver's JIT order can ask for more |
| Withdrawal | Releaser transfers selected full balances | Vault Relayer sells one or more independent full balances |
| Burn sink | `Firepit` | `Burner` |
| Discovery | Factory events and offchain search | Factory events and solver indexing |
| Oracle | None | None |
| Routing | Searcher | Solver |

TJAR releases inventory for a fixed payment. In a Silo, the minimum output can decline to an immutable floor. A full fill restarts the auction for that sell token. The settlement sends the resource token to the configured recipient.

Silo needs CoW infrastructure support. TJAR does not need a batch-auction allowlist.
